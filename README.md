# ActionHouse (AH)

**ActionHouse** is a modern, fast, and highly customizable Auction House plugin for Minecraft servers. It allows players to easily buy and sell items through a clean GUI using the familiar **/ah** command.

## Features

* 🛒 Simple and intuitive Auction House GUI
* 💰 Sell items with custom prices
* ⚡ Fast and optimized performance
* 🔍 Search and filter listed items
* 📦 Item expiration system
* 💸 Economy plugin support (Vault compatible)
* 🔒 Fully permission-based
* 🎨 Customizable messages and configuration
* 🌍 Multi-language support
* 📱 Works on Spigot, Paper, and compatible forks

## Commands

* `/ah` – Open the Auction House
* `/ah sell <price>` – List the item in your hand for sale
* `/ah reload` – Reload the plugin configuration *(Admin)*
* `/ah admin` – Open the admin panel *(Admin)*

## Permissions

* `actionhouse.use` – Access the Auction House
* `actionhouse.sell` – Sell items
* `actionhouse.admin` – Administrative commands
* `actionhouse.reload` – Reload the configuration

## Why ActionHouse?

ActionHouse is designed to be lightweight, reliable, and easy to use while providing all the essential Auction House features players expect. Whether you run a survival, economy, or RPG server, ActionHouse helps create a player-driven marketplace with minimal setup.
